# Privacy Policy for UTZLINE Site Measure

UTZLINE Site Measure is built as a local utility application. Your privacy is critically important to us.

### 1. Data Collection & Transmission
UTZLINE Site Measure does not collect, store, or transmit any personal identification data, analytics, or usage statistics to external servers. 

### 2. File and Permission Access
The application requires local file system access permissions solely to allow users to load, view, and annotate their own PDF project plans and site photos locally on their own devices.

### 3. Cloud Synchronization
Any cross-platform synchronization functionality (such as linking folders via Dropbox, OneDrive, or similar services) is entirely configured, owned, and managed by the end-user. We do not host, store, or have access to any data synchronized through these third-party providers.
